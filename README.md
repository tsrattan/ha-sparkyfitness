# SparkyFitness Home Assistant App

Home Assistant App packaging for SparkyFitness.

This repository provides a Home Assistant OS / Supervisor managed installation
of SparkyFitness.

Upstream project:
https://github.com/CodeWithCJ/SparkyFitness

SparkyFitness is developed by CodeWithCJ. This repository is an independent
Home Assistant packaging project and is not affiliated with the upstream project.

## Installation

1. Open Home Assistant.
2. Go to Settings → Apps → App store.
3. Open Repositories.
4. Add:

   https://github.com/tsrattan/ha-sparkyfitness

5. Install SparkyFitness.
